# Model

Model development. Training runs on Google Colab.

## Structure

- `notebooks/` — Jupyter notebooks for model development and experimentation
- `requirements.txt` — Colab dependency reference (torch, etc.)

## Workflow

1. Open notebooks in Google Colab for training runs
2. Use `requirements.txt` as a reference for Colab dependencies
3. For local notebook editing, run `nix develop` from the repo root to get JupyterLab
